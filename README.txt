GO SKY TRAVEL WEBSITE
====================

Files:
- index.html
- style.css
- script.js

FREE PUBLISHING (GitHub Pages):
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository named: goskytravels.github.io
3. Upload index.html, style.css and script.js.
4. Open Settings > Pages.
5. Select Deploy from a branch, choose main / root, and save.
6. Your free website will be available at:
   https://goskytravels.github.io/

The website uses image URLs from Unsplash. For a fully self-contained site, download your preferred images and place them in an images folder, then update style.css.
